# Familiar VTT Interface style guide

Use the established near-black shell, warm light text, violet selection and blue keyboard focus. All values come from styles/tokens.css. Use Foundry native dialogs, buttons, file pickers and fonts. No bundled fonts or external artwork.

## Rulings

- 2026-09-18: Map navigation stays a compact top row. Tool names appear on hover only.
- 2026-09-18: Image folders belong in the Scenes sidebar. Folder lists use flat rows with adjacent actions. Native file selection and scene creation retain their existing behavior. Connecting external storage must explain the server step honestly; no simulated connection or automatic image copying.

## Acceptance

Verify empty and saved-folder states, native selection, keyboard access, setup validation, missing-folder recovery and installed desktop presentation. Keep the map dominant when dialogs are closed.
